## 🚀 Cómo Usar

1. Clonar el repositorio:
```bash
git clone https://github.com/magaliz99/Mrosas.porfolio.git
```

2. Abrir `index.html` en el navegador o desplegar en Vercel

1. Conectar el repositorio a Vercel
2. Vercel detectará automáticamente que es un proyecto HTML estático
3. El portafolio estará disponible en tu dominio de Vercel
